# 豌豆镇大冒险 · PEA TOWN ROGUE

欧美卡通风格 · 竖屏肉鸽（Roguelike）小游戏。**纯静态网页，打开链接就能玩**，手机 / 微信内直接点开即可，无需安装。

---

## 一、怎么跑起来

### 本地预览
```bash
cd /workspace
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```
（不能直接双击 `index.html`，因为要加载 `vendor/phaser.min.js`，`file://` 协议会被浏览器拦截。）

手机同局域网预览：`http://<你电脑的局域网IP>:8080`

### 上线拿链接
整个目录是纯静态站，**没有构建步骤**，直接把 `index.html`、`js/`、`vendor/`、`assets/` 上传到任意静态托管即可：

| 方式 | 说明 |
|---|---|
| 自有服务器 / Nginx / OSS / COS | 全量上传，最省事 |
| GitHub Pages / Vercel / Netlify | 仓库根目录直接部署 |
| 微信内分享 | 用 HTTPS 域名打开即可；页面已关闭滚动/长按菜单、竖屏优先、点按解锁音频 |

> 必须 HTTPS（微信内访问非 HTTPS 域名会被拦截）。

## 二、怎么玩

- **移动**：手指按住屏幕任意位置拖动（摇杆会出现在按下处）；电脑用 `WASD` / 方向键。
- **攻击**：全自动，朝最近敌人开火，你只管走位。
- **受伤规则**：小怪攻击 -1 格，精英 -2 格，Boss -3 格；受伤后有短暂无敌时间。
- **护盾**：小怪/精英概率掉落护盾道具（5 级：初级挡 1 格 → 顶级挡 5 格），拾取后环绕身边，每次被击中消耗 1 格；捡到更高级的直接换装，同级以下则充满。
- **血量上限道具**：小怪/精英概率掉落「生命上限 +20」道具（爱心加号），拾取即 +20 上限并回 20 点。
- **升级**：吃经验宝石升级 → 三选一（新武器 / 技能升级 / 强化 / 被动）；已拥有的武器再抽到会**升级（最高 Lv.8）**。
- **Boss**：每 5 关一个（第 5 关石头人、第 10 关狂暴石头人）；**第 15 关是终局大 Boss「豌豆王」**——会跳跃震地、环形弹幕、召唤小怪、残血狂暴冲刺，击败它即全通关。

### 金币 / 研究所 / 商店
- **金币**：打怪概率掉落，拾取自动入账（跨局保留）。
- **研究所**（主界面右侧按钮）：花金币做永久强化（伤害 / 攻速 / 移速 / 生命上限 / 拾取范围 / 金币获取），每局都生效。
- **商店**（主界面左侧按钮）：花金币购买**头像**与**头像框**，两大类分栏放置；购买后自动装备，点主界面中央头像也可快捷进入。装扮跨局保留。

### 头像与头像框
- 标题页中央显示当前头像 + 头像框，商店里可随时更换（头像、头像框互相独立，自由搭配）。
- 彩虹框装备后会在头像外圈缓慢旋转。

### 通关时间榜
- 首次击败终局 Boss 即通关，用时自动记入「通关时间榜」（主界面 🏆 按钮 / 结算页入口）。
- 目前是**本地榜**：与自己的历史成绩对比，结算页会提示「新纪录！比上次快 xx」或「慢了 xx」。
- 结构已按联网设计：以后接服务器时只需替换 `js/ui/leaderboard.js` 里的 `R.Leaderboard.fetch`，其余不用动。
- **结算**：血量归零结束，显示到达关卡 / 时间 / 击杀 / 等级 / 已获强化，最佳记录存本地。
- **波次**：每关分 3 波，一波比一波多、精英概率逐波提高；精英怪必掉宝箱。打完最后一波 → 掉宝箱 → 走进传送门进下一关。
- **研究所**：金币是永久货币（拾取即入账）。标题页「研究所」用金币购买永久强化：伤害 / 攻速 / 生命 / 移速 / 拾取 / 金币获取，每局自动生效，存本地。
- **暂停**：战斗中右下角 ❚❚ 按钮 → 继续闯关 / 退出对局。
- **UI 自定义**：标题页左上角 🎨 按钮 → 上传图片替换任意界面组件（按钮/卡片/面板），详见 `美术资源清单.md` 第六节。

## 六、已知问题修复记录

### 手机摇杆位置漂移（已修复）
**现象**：手指按下的位置和摇杆出现的位置对不上，摇杆会"随机"出现在屏幕任意地方。

**原因**：摇杆图形没有固定在屏幕坐标系（缺 `setScrollFactor(0)`）。相机每帧跟随玩家滚动，
导致摇杆跟着世界坐标一起被"拖走"，看起来就像随机出现。

**修复**（`js/scenes/Game.js` 的 `buildStick / setupInput`）：
1. 摇杆基座和圆点都加了 `setScrollFactor(0)`，固定在屏幕层；
2. 始终使用指针的屏幕坐标 `p.x / p.y`（不是世界坐标）；
3. 加了屏幕安全边距（30px），摇杆不会被夹到屏幕外；
4. 点右下角暂停/音效按钮时不再触发摇杆（UI 区域排除）；
5. 暂停/松手/手指离开屏幕时都会正确收起摇杆。

如果你要自己调整摇杆手感，相关参数都在 `setupInput` 里：
- `MAX_R = 70`：摇杆最大拖动半径（越大越"迟钝"，越小越灵敏）
- `clampToScreen` 的 `m = 30`：离屏幕边缘的最小距离
- `onUI`：哪些屏幕区域不算摇杆（右下角按钮区）

## 七、地图建筑物（场景物品占位）

每关随机生成 4~7 个带碰撞体积的建筑（小屋/岩石/树/木箱/灌木/水井/墓碑/石柱）：

- **人物、怪物无法穿过**：物理碰撞体，撞上会被挡住
- **子弹无法穿过**：玩家子弹撞上消失（爆裂弹照常引爆）；敌人子弹同样被挡 → 建筑可以当掩体
- **不会造成卡位 bug**：
  - 不压玩家出生点（中心 200 范围净空）
  - 建筑之间保持 110 通道宽度，互不重叠
  - 不贴地图边缘（边距 150）
  - 刷怪点、传送门、Boss 召唤的小怪全部自动避开建筑
- 全部参数在 `js/core/data.js → D.OBSTACLES`（数量/边距/安全距离/种类与权重）
- 换正式美术：PNG 放 `assets/ob_house.png` 等同名文件（清单见 `美术资源清单.md`）

## 八、UI 可视化调整（?uiedit=1 编辑模式，v0.8.12+）

主城与战斗界面的**所有 UI 组件**都可以在游戏里拖拽调整位置，不用改代码：

1. 浏览器打开 `index.html?uiedit=1` 进入主城编辑模式（23 个组件全部可拖：信息区、金币组、建筑、建筑标签、底栏按钮、声音等）
2. 点「出战」进战斗继续编辑战斗界面（18 个组件：通关时间/获得金币四件套、横幅、进度条、buff 面板等；编辑时自动无敌 + 摇杆禁用）
3. 拖动任意组件，**松手自动保存**；拖「底框」时组内成员整组平移，点文字/图标本体只动它自己
4. 底部四个按钮：**下载布局**（导出 json）/ **导出坐标** / **重置默认** / **完成退出**

**布局生效优先级**：本机草稿（localStorage）> `assets/ui/city-layout.json` / `battle-layout.json`（项目定稿文件）> 代码默认值。

**要让所有设备 / 线上链接统一生效**：调好后点「下载布局」，把 json 放进 `assets/ui/` 提交上线（清缓存也不丢）。若本机旧草稿遮住文件效果，进 `?uiedit=1` 点「重置默认」清掉即可。

改代码默认值：主城在 `Title.js → CITY_DEFAULTS`，战斗在 `js/ui/hud.js → BP`。

> 【遗留】`?dev=1` →「UI 布局调试」（layoutdebug.js）是旧版 HUD 布局系统，v0.8.14 战斗 HUD 重制后已不被引用，仅保留兼容。

## 十三、如何改成像素风格（Pixel Art）

可以，分三步，改动量很小：

**第 1 步：全局开像素渲染（1 行）**

`js/main.js` 创建 game 的 config 里加：

```js
pixelArt: true,      // 关闭图片平滑，像素放大不发糊
roundPixels: true,   // 坐标取整，避免抖动
```

**第 2 步：替换美术素材（放文件即可）**

- 所有占位图尺寸见 `美术资源清单.md`，按同名文件放进 `assets/`：
  如 `assets/player.png`（建议画成 32×32 或 48×48 的像素图），
  代码里 `setDisplaySize` 会自动无损放大到 96×96 显示。
- 怪物 / Boss / 建筑（ob_*）/ 皮肤（skin_*）/ 头像（av_*）同理。
- ⚠ 头像框 fr_rainbow 之类有旋转动效的图，像素画也 OK（pixelArt 下旋转是硬边）。

**第 3 步：换像素字体（可选）**

- 当前字体是 `Baloo 2 / 系统圆体`（见各文件顶部 FONT 常量）。
- 中文像素字体推荐开源的「Fusion Pixel / 缝合像素字体」，或 Zpix；
  下载 woff2 放 `assets/fonts/`，`index.html` 里 `@font-face` 引入，
  再把 FONT 常量换成 `'"Fusion Pixel",monospace'` 即可全局生效。
- 英文可用 Google Fonts 的 "Press Start 2P"（只有英文数字）。

**注意事项**

- 像素图请按「设计尺寸 = 显示尺寸 ÷ 整数倍」来画（如显示 96px 就画 32px 的 3 倍图），非整数倍会变形。
- 程序绘制的占位图（圆脸卡通风）和像素素材混搭会不协调，建议要么全换，要么先换主要角色和怪物。
- UI 面板如果想要像素风边框，把 `assets/ui/panel.png` 等换成像素风九宫格即可（UISkin 优先读 assets/ui/）。

## 十四、版本号与更新日志

**在哪编辑**：`js/core/data.js` 顶部

```js
D.VERSION = '0.8.16';         // 版本号（标题页显示）

D.CHANGELOG = [
  {
    version: '0.8.16',         // 与 D.VERSION 保持一致
    date: '2026-11-10',
    title: '一句话主题',        // 显示在标题页按钮上
    tag: 'new',                // new 新内容 / fix 修复 / opt 优化 / dev 开发
    items: [
      '更新内容第一条',
      '更新内容第二条'
    ]
  },
  // 旧版本放后面，玩家可以往下翻
];
```

**每次发版的操作**：
1. 在 `D.CHANGELOG` 数组**最前面**加一条新版本（含 items 更新简介）
2. 把 `D.VERSION` 改成对应版本号
3. 完成。标题页会自动显示「v版本号 · 一句话主题 ›」按钮，点开是完整的更新日志页（支持滚动，最新版本黄色高亮）

标签颜色：绿=新内容、蓝=修复、橙=优化、紫=开发（在 `D.CHANGELOG_TAGS` 可改）。
