# 豌豆镇大冒险 · PEA TOWN ROGUE

欧美卡通风格 · 竖屏肉鸽（Roguelike）小游戏。**纯静态网页，打开链接就能玩**，手机 / 微信内直接点开即可，无需安装。

---

## 一、怎么跑起来

### 本地预览
```bash
cd /workspace
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```
（不能直接双击 `index.html`，因为要加载 `vendor/phaser.min.js`，`file://` 协议会被浏览器拦截。）

手机同局域网预览：`http://<你电脑的局域网IP>:8080`

### 上线拿链接
整个目录是纯静态站，**没有构建步骤**，直接把 `index.html`、`js/`、`vendor/`、`assets/` 上传到任意静态托管即可：

| 方式 | 说明 |
|---|---|
| 自有服务器 / Nginx / OSS / COS | 全量上传，最省事 |
| GitHub Pages / Vercel / Netlify | 仓库根目录直接部署 |
| 微信内分享 | 用 HTTPS 域名打开即可；页面已关闭滚动/长按菜单、竖屏优先、点按解锁音频 |

> 必须 HTTPS（微信内访问非 HTTPS 域名会被拦截）。

## 二、怎么玩

- **移动**：手指按住屏幕任意位置拖动（摇杆会出现在按下处）；电脑用 `WASD` / 方向键。
- **攻击**：全自动，朝最近敌人开火，你只管走位。
- **受伤规则**：小怪攻击 -1 格，精英 -2 格，Boss -3 格；受伤后有短暂无敌时间。
- **护盾**：小怪/精英概率掉落护盾道具（5 级：初级挡 1 格 → 顶级挡 5 格），拾取后环绕身边，每次被击中消耗 1 格；捡到更高级的直接换装，同级以下则充满。
- **血量上限道具**：小怪/精英概率掉落"生命上限 +1"道具（爱心加号），拾取即加 1 格上限并回 1 格。
- **升级**：吃经验宝石升级 → 三选一（新武器 / 技能升级 / 强化 / 被动）；已拥有的武器再抽到会**升级（最高 Lv.8）**。
- **Boss**：每 5 关一个（第 5 关石头人、第 10 关狂暴石头人）。
- **结算**：血量归零结束，显示到达关卡 / 时间 / 击杀 / 等级 / 已获强化，最佳记录存本地。
- **波次**：每关分 3 波，一波比一波多、精英概率逐波提高；精英怪必掉宝箱。打完最后一波 → 掉宝箱 → 走进传送门进下一关。
- **研究所**：金币是永久货币（拾取即入账）。标题页「研究所」用金币购买永久强化：伤害 / 攻速 / 生命 / 移速 / 拾取 / 金币获取，每局自动生效，存本地。
- **暂停**：战斗中右下角 ❚❚ 按钮 → 继续闯关 / 退出对局。
- **UI 自定义**：标题页左上角 🎨 按钮 → 上传图片替换任意界面组件（按钮/卡片/面板），详见 `美术资源清单.md` 第六节。

## 三、目录结构

```
index.html                 入口（脚本顺序 = 场景注册顺序，别随意调）
assets/                    正式美术/音频，放同名文件自动覆盖占位图
vendor/phaser.min.js       引擎本地兜底（CDN 挂了也能跑）
js/
  main.js                  启动 + 事件总线 R.on / R.emit
  core/data.js    ★        全部数值与内容配置（改游戏先看这里）
  core/art.js              程序化占位美术（正式图会覆盖它）
  core/sfx.js              WebAudio 合成音效（不依赖音频文件）
  core/run.js              一局的状态机（血量/经验/武器/buff）
  core/boot.js             缩放适配与可选资源加载
  scenes/Preload.js        资源加载 + 生成占位图
  scenes/Title.js          标题页
  scenes/Game.js           主战斗场景（刷怪/Boss/掉落/传送门/碰撞）
  ui/hud.js                血条 / 经验条 / 武器槽 / 公告
  ui/upgrade.js            升级三选一（独立叠加场景）
  ui/result.js             结算页
  systems/registry.js ★    扩展注册表（新玩法从这里挂）
美术资源清单.md            交给画师/外包的清单
玩法接入指南.md            加敌人/武器/章节/Boss 的具体做法
```

## 四、后续加内容（一句话版）

- **换美术**：把 PNG 按 `美术资源清单.md` 的 id 命名丢进 `assets/`，刷新即生效，不改代码。
- **加怪 / 加武器**：`js/core/data.js` 加一条配置，进章节 `pool` 就生效。
- **加新玩法机制**：`js/systems/registry.js` 用钩子（`roomStart` / `kill` / `levelUp` …）挂载，不动核心场景。
- 细节见 `玩法接入指南.md`。
